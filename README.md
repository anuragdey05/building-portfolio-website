# Responsive Website Template

A fully responsive, mobile-first website template built with **Vite, HTML, CSS, and JavaScript**. This template includes multiple sections, supports light and dark modes, lazy loading for better performance, and is optimized for mobile and desktop experiences.

## Features
- **Mobile-First Design**: Optimized for mobile devices and scales up for larger screens.
- **Light & Dark Mode**: Built-in theme toggle.
- **Lazy Loading**: Images and content load dynamically to improve performance.
- **Fully Responsive**: Works across all screen sizes.
- **Modular Sections**: Easily customizable structure for different use cases.

## Technologies Used
- **Vite** for fast development and build performance.
- **HTML5** for semantic structure.
- **CSS3** for styling and responsiveness.
- **JavaScript (ES6+)** for interactivity.

## Installation & Usage
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/your-repo-name.git
   ```
2. Navigate to the project folder:
   ```sh
   cd your-repo-name
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Run the development server:
   ```sh
   npm run dev
   ```
5. Build for production:
   ```sh
   npm run build
   ```
